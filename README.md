# Reminders

Reminders is a modern, responsive task management app built with plain HTML, CSS, and JavaScript. It helps you organize tasks with priorities, due dates, categories, search, filtering, sorting, progress tracking, and theme switching.

## Overview

This project is designed to feel clean, polished, and practical for everyday reminder and task management. The interface is lightweight, fast, and works entirely in the browser without any build step.

## Features

- Add, edit, complete, and delete tasks
- Set a due date and optional reminder time
- Assign priority levels: Low, Medium, High
- Organize tasks by category
- Search tasks instantly
- Filter tasks by All, Active, or Completed
- Sort tasks by newest, oldest, due date, or priority
- Track overall progress with visual stats
- Toggle between light and dark themes
- Save tasks locally in the browser using local storage
- Show toast notifications and optional browser notifications

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
- Web Notifications API

## Project Structure

- index.html — Main app structure and UI markup
- style.css — Styling, responsive layout, and theme support
- script.js — App logic for task management, rendering, persistence, and interactions

## Getting Started

1. Open the project folder in your browser.
2. Launch index.html directly, or use a simple local server if you prefer.

Example with Python:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Usage

- Enter a task title and optional details in the form on the left.
- Choose a due date, reminder time, priority, and category.
- Click Add Task to save it to your list.
- Use the toolbar to search, filter, and sort your tasks.
- Click the checkbox to mark tasks as complete.
- Use the action buttons to edit or delete tasks.

## Notes

- Tasks are stored locally in your browser, so they remain available on the same device and browser.
- Clearing your browser storage will remove saved tasks.
- Notification features may require browser permission to be enabled.
